# MD-Chatbox

Aplikacja Android do obsługi Claude API z integracją GitHub.

## Funkcje
- Czat z Claude (opus / sonnet / haiku)
- Wiele równoległych konwersacji z historią
- System prompt per konwersacja
- Przeglądarka repozytoriów GitHub
- Wysyłanie plików z GitHub bezpośrednio do Claude
- Dark / Light mode

## Konfiguracja
1. Otwórz zakładkę **Ustawienia**
2. Wpisz klucz Claude API (`sk-ant-...`) z [console.anthropic.com](https://console.anthropic.com)
3. Wpisz token GitHub (`ghp_...`) z [github.com/settings/tokens](https://github.com/settings/tokens)

## Wymagania
- Android 8.0+ (API 26)
- Android Studio Ladybug lub nowszy
